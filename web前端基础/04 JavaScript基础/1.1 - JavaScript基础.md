### 2javaScript基本结构
```
<script type="text/javascript>
//javascript代码
</script>
该结构可以在HTML中任意位置书写，但必须保证javascript脚本中使用到的元素必须在javascript脚本执行前完成加载
```

### 4JavaScript引入方式
#### 行内脚本
```
<input type="button" value="点击" onclink="alert('你点击的按钮')";>
```
#### 内部脚本
```
<input="button"value=""点击 id="btn">
<script type="text/javascript">
onclick=function(){
alert('你点击的按钮');
}
</script>
```
#### 外部脚本
```
//demo.js
document.getElementById("btn").onclick=function(){
alert('你点击的按钮');
}
```

```
<!--demo.html-->
<input="button"value=""点击 id="btn">
<script type="text/javascript" src="demo.js"
</script>
```
