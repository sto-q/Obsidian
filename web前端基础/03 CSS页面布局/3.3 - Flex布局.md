### Flex属性
有6个属性设置在Flex上
- order
- flex-grow
- flex-shrink
- flex-basis
- flex
- align-self

#### order
```
order属性定义项目的排列顺序。数值越小，排列越靠前，默认为0
.t{
order:<integer>;
}
<div class="child" style="t:3"></div>
<div class="child" style="t:1"></div>
<div class="child" style="t:2"></div>
<div class="child" style="t:4"></div>
```
#### flex-grow
```
flex-grow属性定义项目的放大比例，默认为0，即使有剩余空间也不放大
.t{
flex-grow:<number>;/*dwfault 0*/
}
<div class="child" style="t:4;flex-grow 1.5"></div>
如果所有项目的flex-grow属性都为1，则他们将等分剩余空间（如果有）。如果一个为2其余为1，则2的占据的剩余空间比1的多1倍
```
#### flex-shrink
```
flex-shrink属性定义项目的缩小比例，默认为1，即如果空间不足，则项目将缩小
.t{
flex-shrink:<number>;/*default*/
}
如果所有项目flex-shrink属性都为1，当空间不足时都将等比例缩小，如果一个为0其余为1空间不足时0不变
```
#### flex-basis
```
flex-basis 属性定义了在分配多余空间之前，项目占据的主轴空间，浏览器根据这个属性，计算主轴是否有多余空间，默认值是auto，即项目原来本身大小
.t{
flex-basis<length>|auto;/*default auto*/
}
他可以设为跟width或height属性一样的值（如350px），则项目将占据固定空间
```
#### flex
```
flex属性是flex-grow，-shrink-basis的简写，默认值为0 1 auto。后面两个属性可选
.t{
flex:none|[<'flex-grow'><'flex-shrink'>?||<flex-basis'>]
}
该属性有两个快捷键auto(1 1 auto) none (0 0 auto)
建议用快捷键不是分开写因为浏览器会推演相关值
```
#### align-self
```
align-self属性允许单个项目有于其他项目不一样的对齐方式，可覆盖align-items属性，默认值为auto，表示继承父元素的align-items属性，等同于stretch
.t{
align-self:auto|flex-start|flex-end|center|baseline|stretch
}
```
