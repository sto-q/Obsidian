### 3CSS3渐变
#### 线性渐变--颜色沿着一条直线过度从左到右，从右到左，从上到下等
```
linear-gradient(渐变方向，颜色1....颜色n)
```
```
.blok1{
background:linear-gradient(red,bllue)
}没写默认从上到下
.blok2{
background:linear-gradient(to right red,bllue)
}从左到右
to bottom right从左上角到右下角
```
径向渐变-圆形或椭圆形渐变，颜色不在沿一条直线变化而是从一个点向所有方向扩散
```
radial-gradient(center,shape,size,start-color,...last-color)也可以指定比例
```

### 5字体
```
@font-face{
font-family:必需。规定字体的名称
src:必需 定义字体文件的URL
font-weight:可选。定义字体的粗细默认为"noemal"
font-style: 可选。定义字体的样式默认为"normal"
}
```
```
display:inline-block:呈现方式：在一行中以块级元素的发生呈现
font-size:inherit继承父容器的字体
text-rendering:auto;文本渲染方式为自动渲染
```
### 6变形
![[Pasted image 20260528103223.png]]
#### 6.1平移
```
translate(x,y):平移函数，基于x,y坐标重新定位元素的位置
translateX(x):表示只设置x的位移
translateY(y):表示只设置y的位移
```
```
.t{
width:100px;
height:100px;
background-color:red;
transform:translaste(20px,20px);
}
<div class="t"></div>
```
#### 6.2 2D缩放
```
scale(x,y);缩放函数，可以使任意元素对象尺寸发生变化，当接收一个值时 x，y都是这个值
scaleX(x);表示只设置x的缩放
scaleY(y);表示只设置y的缩放
```
```
transform:scale(0.5);
```
#### 6.3旋转
```
rotate(degree):旋转函数，取值是一个度数值，参数（degree）单位用deg表示，取正值是元素相对原来中心顺时针旋转
```
```
transform:rotate(10deg);
```
#### 6.4倾斜
```
skew(x,y):倾斜函数，取值是一个度数值
shewX(x):表示只设置x的
shewY(y):表示只设置y的
```
```
transform:shew(10deg,10deg);
```
