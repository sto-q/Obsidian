
<h2>1行级标签特征</h2>
a.和其他元素都在一行上
b.高度，行高及外边距和内边距不可改变
c.宽度就是其内容的宽度，不可改变


<h2>4超链接标签</h2>
```
<a href="资源地址" target="目标窗口位置">内容</a>
```
![[Pasted image 20260525220700.png]]
其中target常用的有 
```

_self 在当前窗口打开，是target默认值
```

<h2>输入标签</h2>
![[Pasted image 20260525221632.png]]
```
<input type="hidden" name=""> <!--隐藏域-->
<!--要注意：如果input标签type值为radio或者checkbox时只要标签上存在check属性，则表示该标签默认选中-->
<input type="radio" name=""check>男
则表示男按钮被默认选中
```
name除了采集数据外还有分组的功能
**同一个组内单选按钮只能选择一个当input的type值为submit时，按钮可以提交表单，提交的表单通过name属性采集数据**
<h2>文本域</h2>

```
<!-- label与span都具有范围选择的功能-->

</label>
```
