## 音频标签
```
<!--controls属性控制页面上是否显示音频在就绪后马上播放
loop属性表示音频结束后重新播放
preload值:
auto-当前页面加载后载入整个音频
metadata-当前页面加载后只载入元数据
none-当前页面加载后不载入音频
-->
```
```
<audio src="音频路径" controls="controls" autoplay="autoplay" loop="loop" preload=" metadata"></audio>
```
音频标签可以设置多个音频文件
```
<audio src="音频路径" controls="controls" autoplay="autoplay" loop="loop" preload=" metadata">
<source src="音频路径"/>
<source src="音频路径"/>
</audio>
```

## HTML5新增元素属性
1全局属性

```
<div style="height:100px"hidden></div>
<div style="height:100px"contenteditable="true"spllcheck="true"tabindex="1"></div>
<div style="height:100px"contenteditable="true"spllcheck="true"tabindex="3"></div>
<div style="height:100px"contenteditable="true"spllcheck="true"tabindex="2"></div>
```
[^1]
2表单属性
```
<form action"" method="get">
<input type="text"placeholder="请输入账号"required pattern="[a-z]{8，15}" title="账号只能为8到15位">
<input type="submit" value="">
</form>
```
[^2]
[^1]: contenteditable元素是否允许可编辑内容
	spellcheck是否必须对元素进行拼写或语法检查
	tabindex指定元素的tab键选择次序
	

[^2]: placeholder指定元素的默认提示信息
	required元素内容为必填
	pattern使用正则表达式检查元素内容是否合法
