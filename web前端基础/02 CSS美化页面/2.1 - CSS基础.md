### 4CSS样式引入
行类样式
```
<div style="color:red;font-size:20px;">
</div>//不能复用
```
内部样式
```
<style>
#demo{
color:red;
font-size:20px;
}
</style>
<div id="demo"></div>
```
外部样式
```
/*demo.css*/
#demo{
color:red;
font-size:20px;
}
```
```
<!--demo.html-->
<head>
<link type="text/css" href="demo.css" rel="stylesheet>
</head>
---------
还有一种引入样式,但只适用于CSS3
<style>
@import url(demo.css);
</style>
```

### 5CSS高级选择器
后代选择器
```
div ul li{
}
```
子代选择器
```
div>ul>li{
}
```
[^1]: 外部样式就是创建一个CSS后缀文件将修改样式放进去然后在html中提供CSS路径让html可以访问CSS的内容从而发生改变

[^2]: 行内样式>内部样式>外部样式 优先级
