## 7清除浮动
清除浮动有三种选择:left,right both
清除浮动后与其他元素就在同一层了
清除的是同一个容器中排在borh前面的,后面的不会影响
```
<div class="box">
  <div class="left">左浮动</div>
  <div class="right">右浮动</div>
  <div class="clear"></div>
</div>

.clear {
  clear: both;
}

```
