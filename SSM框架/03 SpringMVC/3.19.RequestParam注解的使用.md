```java
/**  
 * RequestParam 如果前后参数名称不一致，我们可以通过注解实现前后参数的绑定  
 * value/name 表示前端参数名称  
 * required 默认为true 表示当前的参数必须携带 否则报错400异常  
 * defaultValue  当前端没有提交参数 为空就使用defaultValue给默认值替代  
 * @param username  
 * @param age  
 * @return  
 */  
@RequestMapping("textRequestParam")  
public String textRequestParam(@RequestParam(value = "username",required = true,defaultValue = "aa") String username, Integer age){  
    System.out.println(username+"---"+age);  
    return "success";  
}
```
