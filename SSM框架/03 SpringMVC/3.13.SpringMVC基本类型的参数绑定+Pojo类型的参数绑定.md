```java
/**  
 * 如果前端提交的是字面量的数据(简单的字符串或数字) 在控制器方法中，我们值需要保持与前端提交的参数一致即可  
 * @param username  
 * @param age  
 * @return  
 */  
@RequestMapping("getBasicParam")  
public String getBasicParam(String username,Integer age){  
    System.out.println(username);  
    System.out.println(age);  
    return "success";  
}
```
```jsp
<a href="${pageContext.request.contextPath}/demo1/getBasicParam?username=eric&age=10">[提交基本类型的参数]</a>
```


```java
/**  
 * 接收前端提交的表单数据  
 * @return  
 */  
@RequestMapping("getPojoParams")  
public String getPojoParams(Account account){  
    System.out.println(account);  
    return "success";  
}
```
